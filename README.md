# 🏥 Hospital Management System

A modern, full-stack hospital management web application built with **Next.js** and **Django REST Framework**.

The application provides a professional dashboard for doctors to manage patient information and hospital data through a responsive and user-friendly interface.

## 🚀 Features

* 🔐 Secure authentication with JWT and HttpOnly cookies
* 👨‍⚕️ Doctor dashboard
* 🧑‍⚕️ Patient management
* ➕ Add and manage patient records
* 👁️ View patient information
* ✏️ Edit patient records
* 🗑️ Delete patient records
* 📄 Server-side pagination with Django REST Framework
* 🌙 Dark mode support
* 📱 Responsive dashboard
* 🔒 Protected API endpoints
* ⚡ RESTful API architecture

## 🛠️ Tech Stack

### Frontend

* Next.js
* React
* Tailwind CSS
* shadcn/ui
* Lucide React

### Backend

* Django
* Django REST Framework
* JWT Authentication
* Cookie-based authentication

### Database

* SQLite during development
* PostgreSQL-ready architecture

## 🎯 Goal

The goal of this project is to build a practical, production-oriented hospital management system while applying modern full-stack development practices, secure authentication, REST APIs, and scalable frontend architecture.

🚧 **Currently in development**

More hospital management features such as doctor management, room availability, inventory management, and additional dashboard functionality will be added as development continues.
